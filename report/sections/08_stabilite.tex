\section{Stabilité et non-déterminisme}\label{sec:stabilite}

Un agent qui appelle un LLM plusieurs fois peut donner des réponses différentes à la même question. Nous avons exécuté le
graphe complet \NNoiseRuns{} fois sur \NNoiseQuestions{} questions du développement (la première question de chacun des
quatre premiers concepts), chaque fois avec une nouvelle conversation (\texttt{eval/noise\_check.py}). La température du
modèle partagé est fixée dans le code :

Pour \NNoiseSameev{} questions sur \NNoiseQuestions, les six preuves sont identiques d'une exécution à l'autre ; l'indice de
Jaccard moyen entre les ensembles d'articles cités vaut \NNoiseJaccard{} (tableau~\ref{tab:noise}, figure~\ref{fig:noise}).
Ces quatre questions sont toutes en français et toutes du code pénal : ce contrôle ne dit rien de la stabilité en arabe ou en
anglais, ni sur des questions qui déclenchent une clarification. Une température nulle ne garantit pas, en général, des
sorties identiques chez un fournisseur d'API ; ce résultat est une observation sur ces exécutions, non une garantie.
